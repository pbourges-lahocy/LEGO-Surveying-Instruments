# LEGO Surveying Instruments

Real surveying instruments, rebuilt with real LEGO bricks.

This repository contains my personal LEGO recreations of surveying equipment, with **BrickLink Studio files**, **building instructions**, and **parts lists** whenever available.

> I am **not a professional LEGO designer**. These are my very first projects made with BrickLink Studio, so the models and instructions may contain imperfect choices, unusual techniques, or things that experienced builders would do differently. Feedback and improvements are very welcome.

## Why this project?

I kept seeing AI-generated images of surveying instruments built from LEGO bricks. They looked fun, but most of them could not actually be built.

So I wanted to try something different: create models made with **real, existing LEGO parts**, so that anyone interested in surveying and LEGO can actually build them.

## Models

### Leica RTC700

The first completed model in this repository is a LEGO recreation of the **Leica RTC700**.

The idea came after seeing the excellent brick-built RTC prototypes created by **Mei Yee Lai from Leica Geosystems**. Her work inspired me to try my own reconstruction in BrickLink Studio from publicly shared photos, while learning Studio along the way.

Files for the RTC700 are stored in the [`RTC700`](./RTC700) folder.

### Leica TS20

A LEGO version of the **Leica TS20 total station** is currently being designed and will be added later.

## Repository contents

For each completed model, I aim to provide:

- BrickLink Studio `.io` file
- Building instructions
- Parts list / BOM
- Reference renders or photos when available
